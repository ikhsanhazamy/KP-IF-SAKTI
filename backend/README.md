# Backend (Laravel) — Skeleton

Ini adalah skeleton untuk backend Laravel. Untuk membuat project Laravel penuh, jalankan salah satu perintah berikut di direktori `backend`:

Dengan Composer (direkomendasikan jika Composer sudah terpasang):

```bash
cd backend
composer create-project laravel/laravel .
```

Atau gunakan Laravel Sail (Docker) — lihat dokumentasi Laravel untuk detail.

Setelah instalasi, jalankan:

```bash
php artisan serve --host=0.0.0.0 --port=8000
```

Database dan konfigurasi ada di `.env` setelah instalasi.
