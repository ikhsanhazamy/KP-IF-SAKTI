## 🤝 Cara Menjadi Kontributor

Kami menyambut kontribusi dari siapa saja, baik berupa perbaikan bug, penambahan fitur, perbaikan dokumentasi, maupun optimasi performa!

Langkah untuk berkontribusi:
1. Baca pedoman kontribusi di [CONTRIBUTING.md](CONTRIBUTING.md).
2. Patuhi pedoman kode etik di [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
3. Fork repositori ini ke akun GitHub Anda.
4. Buat branch baru untuk fitur atau perbaikan Anda (`git checkout -b feat/nama-fitur`).
5. Kirim Pull Request (PR) dengan deskripsi yang jelas dan referensi ke Issue terkait.
6. Setelah PR Anda di-merge, tambahkan nama Anda pada daftar kontributor di dokumen ini.
